# 3.5.2-alpha.1 — Keep Awake troubleshooting

Adds a short guide below Keep Awake: Samsung Settings → search “Lock when folded” → turn it OFF → return to Home and fold to test. The owner confirmed this resolves their Keep Awake issue. No privileged settings or animation behavior changed.

Renderer review: Animated Reflection already uses the cover renderer with a horizontal flip, including V2, Early stretch, End stretch and Startup easing. Frosted Reflection remains a separate static blurred image. No additional projection changes were made.

3.5.1 remains the official release.
