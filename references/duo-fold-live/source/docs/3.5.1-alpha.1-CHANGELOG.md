# 3.5.1-alpha.1 — Optional V2 Window Reveal

- Advanced → Screen placement offers Original and V2 Window Reveal. Original remains the default and retains the existing projection.
- V2 samples a fixed content plane behind the glass: hinge movement no longer compresses/stretches the sampled image or pulls its corners inward. Blur, shading and fades still follow the hinge.
- Applies to all four animation styles, both glass renderers, screenshot content and the animated reflection. Fold-only/unfold-only still respect their direction settings. Frosted Reflection keeps its existing static placement.
- Existing preview layout, capture crops, handoff timing, AA settings and Keep Awake are unchanged. This experiment does not provide unseen inner-screen content while the cover is active.
- The status report identifies the selected placement. Compare the same content and settings in both modes, opening slowly and reversing mid-motion. Device testing is required to judge the visual result.

3.5.0 remains the official release.
