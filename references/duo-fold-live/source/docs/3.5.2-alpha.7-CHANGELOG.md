
## Independent vertical-compression controls

- Add a 0–200% vertical-compression slider and reset button to both cover and inner animation cards.
- Both default to 100%, which explicitly bypasses the adjustment and preserves the existing appearance. No saved stretch settings are reset.
- 0% removes the vertical displacement; 200% doubles it. Horizontal stretch, hinge timing, and handoff remain unchanged. The control follows the animation's axes when rotated.
- Classic glass has no vertical projection/compression to scale and remains unchanged; the settings explain this limitation.
- Status reports include both compression values.
