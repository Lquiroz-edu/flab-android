# 3.5.1-alpha.9 — V2 defaults and startup toggle

- V2 Window Reveal is the default for unset preferences and remains labeled experimental. Original remains selectable; existing explicit choices are preserved.
- Startup easing now has an Advanced toggle, enabled by default. Turning it off disables all three startup adjustments: geometry easing, shorter opacity ramp and near-closed initial angle seeding.
- End stretch extends from 80% to 150% on the same scale. Enhanced end stretch remains enabled by default; default/reset remains 100%, with the same appearance as alpha.8.
- Early stretch stays at 0–100%, default/reset 90%. Saved settings remain intact.

Tests/build do not replace device visual testing. This is a prerelease; 3.5.0 remains the official release pending approval.
