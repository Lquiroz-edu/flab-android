
## Duo Fold Live 3.5.2

Promotes the tested alpha.7 feature set with three default/reset adjustments:

- Cover vertical compression: **115%**.
- Inner vertical compression: **60%**.
- Inner end stretch: **45%**.

Inner early stretch remains 30%; all other defaults and animation math remain unchanged. Previously saved manual selections remain intact; use the corresponding reset buttons to apply these defaults.

### Included since 3.5.1

- Independent inner-display V2 stretch and easing controls, with separate cover/inner settings cards.
- Independent vertical-compression sliders; Classic glass remains unchanged because it has no vertical compression to scale.
- Corrected low inner stretch so it reduces outward motion without an inward squeeze; 0% means no horizontal stretch.
- Stale-shadow clearing and fallback diagnostics.
- Independent rotation recovery on reader-process exit and graceful release before normal shutdown. Recovery cannot guarantee immediate cleanup if both processes are terminated together or the device reboots.
- Keep Awake troubleshooting for Samsung's “Lock when folded” setting.

The Samsung panel handoff blackout and occasional custom-wallpaper unlock flash remain documented limitations. This is the latest official release, not a prerelease.
