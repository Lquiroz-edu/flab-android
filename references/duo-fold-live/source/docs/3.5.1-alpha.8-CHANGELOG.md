# 3.5.1-alpha.8 — Stretch controls and eased startup

- Early stretch is relabeled 0–100%: old 300% = new 100%. Stored values keep their exact curve; default/reset is new 90% (old 270%).
- V2 adds Enhanced end stretch (enabled by default) and an 80–100% slider. 80% or toggle off reproduces the previous end mapping; 100% adds 25% horizontal magnification, blended in late in the cover animation. The handoff angle is unchanged.
- V2 cover startup completes its opacity ramp before easing geometry away from the unwarped content, reducing overlap between live and transformed images. A newly created cover surface near closed starts angle smoothing from zero rather than snapping to its first reading. These changes target startup jitter/ghosting but need device validation.
- Top/bottom perspective returns to the original mapping after the short startup easing. Original mode, inner rendering and Keep Awake are unchanged.

3.5.0 remains the official release. Existing users keep saved early-stretch values (e.g. old 300% displays as 100%); Reset early stretch selects the new 90% default.
