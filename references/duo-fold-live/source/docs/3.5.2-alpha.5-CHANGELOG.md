
## Fix inner-display compression at low stretch settings

The alpha.4 range extension reused the high-stretch division below 80%. Its divisor dropped below one, expanding source coordinates and causing inward compression followed by outward motion.

- Inner end stretch below 80% now scales horizontal displacement toward the flat image instead of inverting the stretch multiplier.
- Inner slider now includes 0%: no horizontal stretch throughout the animation. Vertical perspective, blur, and shading remain active.
- Inner values from 80–150%, cover animation, reflected preview, defaults, and handoff angles are unchanged.
- Status reports now label cover settings and separately include inner early/end stretch and easing.
- Regression checks compile the actual scalar shader functions, testing both styles, both layouts, full animation sweeps, all sampled early/end settings, zero stretch, and preservation of 80–150% behavior. These checks also run in CI.

Device visual confirmation remains necessary.
