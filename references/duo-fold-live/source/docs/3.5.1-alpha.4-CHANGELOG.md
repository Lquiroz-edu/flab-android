# 3.5.1-alpha.4 — Reverse the initial cover squeeze

V2 now reflects the original early cover sampling overshoot around its untransformed position, turning the inward squeeze into an outward stretch from the beginning. This is a direct reversal experiment, not a new progression curve.

Only cover sampling during the original overshoot changes. Later horizontal projection, top/bottom perspective, shading, inner projection, preview placement and handoff remain as in alpha.3. The maximum-stretch endpoint is unchanged. Reversing the hinge follows the same geometry back.

Select Advanced → Screen placement → V2 Window Reveal. Original remains available and the default. Compare early opening against alpha.3; validate on-device before promotion. 3.5.0 remains the official release.
