
## Rotation cleanup and stale shadow diagnostics

- Preserve the existing rotation lock during animations, with an independent shell recovery process prepared before any hold is applied. If the angle-reader process exits during uninstall, an update, or a crash, pipe closure triggers restoration from the existing saved-settings journal.
- Wait for normal rotation cleanup before terminating the Shizuku reader. Recovery uses the same cross-process lock and saved panel/posture settings; it does not indiscriminately enable auto-rotate.
- Explicitly clear a retained glass effect at the closed endpoint or when live angles become stale/effects are suspended. Log changes into and out of the fallback shadow to distinguish missing captures from a shader failure.
- Includes the Keep Awake troubleshooting added in alpha.1.

This is a test prerelease. Device validation is still required, particularly uninstalling mid-animation and checking rotation on both panels. Android does not deliver an uninstall callback to the removed app. The separate recovery helper handles owner-process exit, but simultaneous termination of both processes or a reboot can prevent immediate cleanup; the existing durable journal remains available for recovery on a subsequent installation/start. Transient recovery failures are retried for up to ten minutes.
