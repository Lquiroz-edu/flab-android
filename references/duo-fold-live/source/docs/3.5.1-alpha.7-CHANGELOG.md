# 3.5.1-alpha.7 — Early stretch up to 300%

Early stretch defaults and resets to 150%, exactly matching the previous 150% curve. The slider extends to 300% on the same scale; saved selections remain preserved.

The additional range increases early stretch without changing the final stretch, curve join, top/bottom perspective, Original mode or other settings. Shader compilation and curve derivative checks passed through 300%; device testing is still needed for visual preference.

3.5.0 remains the official release.
