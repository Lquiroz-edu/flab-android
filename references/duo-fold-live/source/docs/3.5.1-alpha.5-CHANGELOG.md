# 3.5.1-alpha.5 — Continuous early stretch

V2 replaces the temporary outward bump with continuous horizontal stretch from the start. Advanced → Screen placement → V2 reveals an Early stretch slider (0–100%, default 50%) and reset button. Higher values increase the initial stretch rate.

A monotonic cubic joins the original cover projection at 60° (legacy Classic renderer: 1.5 radians of its existing projection angle), matching position and slope. Later projection and maximum stretch remain unchanged. Top/bottom perspective, inner mapping, handoff, AA and Original mode are preserved. Settings persist across updates and the report includes the slider value.

Compare slow opening, reversing mid-motion, and closing. This remains a device-testing prerelease; 3.5.0 is still the official release.
