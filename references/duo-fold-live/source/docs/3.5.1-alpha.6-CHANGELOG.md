# 3.5.1-alpha.6 — Early stretch up to 150%

Early stretch now defaults and resets to 100%. The slider extends to 150% without rescaling: all existing 0–100% values retain the same curve, and values above 100% increase early stretch. Saved choices remain preserved across updates.

Final stretch, curve join, top/bottom perspective, Original mode and other settings are unchanged. 3.5.0 remains the official release.
