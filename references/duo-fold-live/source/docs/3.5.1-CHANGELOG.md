# 3.5.1 — Main release

Promotes the user-tested 3.5.1-alpha.9 with exactly two setting changes:

- End stretch default/reset: **125%**, preserving the existing scale and 150% maximum.
- Glass strength default/reset: **100%**.

These two values are applied once on the first app-process startup after installation or upgrade, before the UI or service reads settings. No manual reset is required. Subsequent user changes are retained; restarting or reinstalling an update does not repeatedly reset them. Other saved settings and defaults are preserved.

Includes the tested V2 Window Reveal (still experimental, default for unset preferences), Early stretch default 90%, Startup easing toggle on by default, and Enhanced end stretch on by default. Original remains selectable.

Known issues remain: Samsung display-switch blackout, occasional custom-wallpaper unlock flashes, unreliable Keep Awake, and occasional transition glitches. Earlier releases remain downloadable.
